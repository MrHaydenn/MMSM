# MMSM 0.9.0

This stable release includes all verified features since 0.8.1:

- Granular account and per-server permissions, including permission to create servers and full control of creator-owned servers.
- Independent sleep/RAM/AutoStart/properties settings on synced servers, selective edit/unlink warnings, and template copy/sync creation.
- Five-minute idle timer verification, visible sleep diagnostics, join-only automatic wake, reconnect messages and bounded wake history. Server-list pings leave servers asleep.
- UNM DNS integration, domain cleanup, available-port allocation and account username improvements.
- Privacy cleanup: personal network/server examples replaced with generic examples.
- Simplified Windows distribution with start.bat as the only launcher and Windows installation/upgrade instructions at the top of the README. Shell, Docker and systemd startup files removed.

Use MMSM Settings → Stable → Check for updates to install in place. Stop Minecraft servers and finish background operations before updating. Accounts, worlds and local settings are preserved. For a new Windows installation, download MMSM-0.9.0.zip and follow its README; the update ZIP is intended for the built-in updater.
